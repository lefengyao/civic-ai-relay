# 2026-10-18

## 生产环境升级 v0.3.2 → v0.3.8（阿里云 2c2g，经 OpsHelper MCP）

老板指令「civic-relay，更新这台容器」。全程通过 ServerOpsHelper MCP 的 SSH 通道完成。

### 事实基线
- 部署目录 `/opt/civic-relay`（compose 项目名 = 目录名），卷 `civic-relay_civic-relay-config` / `civic-relay_civic-relay-data`。
- 升级前跑的是 v0.3.2（9/16 部署），已运行 4 周 healthy。
- 本地 v0.3.7 发布包**落后于代码**：9/25 打包，10/3（结算/流式/请求记录重构）与 10/7（CORS）的改动都没进去。不能直接拿 v0.3.7 升级。
- 全新版本号定为 **v0.3.8**，包含上述全部改动。

### 做了什么
1. `gofmt -l` 干净；`GOPROXY=off go test -count=1 ./...` 10 个包全绿（约 2 分钟）。
2. 用原 `Dockerfile.relay` 构建镜像，本地隔离卷跑起来验证 `/healthz` `/readyz` 均返回 v0.3.8。
3. `python scripts/package_release.py v0.3.8` 产出 dist 三个包（镜像 5.78MB / deploy 6.00MB / src 0.22MB）+ SHA256SUMS。
4. 服务器：停机 → 一致备份 → 改 `.env` 版本 → `docker compose up -d`。
5. 验证：容器 healthy、`healthz`/`readyz` 返回 v0.3.8、公网 `http://114.55.54.195:8000/healthz` 返回 v0.3.8、日志「已检测 1 个分组」说明配置与库都在。

### 备份（回滚点）
`/opt/civic-relay/backups/` 下两份：
- `pre-v0.3.8-20261018-155041.tar.gz`（在线备份，57K）
- `upgrade-v0.3.2-to-v0.3.8-20261018-155421.tar.gz`（**停机后备份，一致**，56K，含 relay.env + relay.db）
回滚：`sed -i 's/v0.3.8/v0.3.2/' .env && docker compose up -d`（v0.3.2 镜像仍在）。注意新版本已执行 schema 迁移，回滚前若要保数据需恢复这份卷备份。

### 踩坑（重要，下次直接抄）
- **本机拉不到 Docker Hub**：`auth.docker.io` 报 Bad Gateway / 超时（清 `HTTP_PROXY` 也无用）。解法：`docker pull mirror.gcr.io/library/golang:1.27-bookworm`（本机 gcr.io 通），再 `docker tag <它> golang:1.27-bookworm` 让 Dockerfile 的 `FROM` 命中本地标签。
- ~~**服务器无法从本机收文件**：OpsHelper MCP 只有 `exec_command`（SSH）与 `write_file`/`read_file`（SFTP，仅 UTF-8 文本）。二进制没法由我「生成」成参数传过去（base64 也等于要我输出数 MB token）。~~
  **【2026-10-31 更正】这条已不成立**：ServerOpsHelper 现在有 `upload_file` / `download_file`，从本机磁盘直流传输、二进制安全、无 8 MiB 限制（`localPath` 是 Windows 路径，目录要 `recursive=true`）。传镜像包不再需要下面的 git 中转 hack。本次整合实测：14.5 MB 二进制上传 1.6 秒、112 文件源码树下载 37 秒。
- 服务器出网白名单实测：GitHub 200、filebin.net 200、golang.google.cn 200；Docker Hub / gcr.io / mirror.gcr.io 全 FAIL；alpine 源可用。
  **【2026-10-31 补充】以上是阿里云那台。waigame 不一样：GitHub 完全不可达（`github.com` 与 git 智能协议都 000），也没有 Go 工具链**，所以 waigame 上既不能 `git clone` 也不能现场构建 —— 只能本机产出包再上传，见 `docs/deploy-prebuilt.md`。
- 中转站：0x0.st **已关闭匿名上传**（"AI botnet spam"），temp.sh / transfer.sh / catbox / bashupload 本机不可达。
- **最终用的通道**：临时 git 仓库 → push 镜像包到 `xfer-v0.3.8` 分支 → 服务器 `git clone --depth 1 -b` → `docker load` → 删远程分支 + 清 `/tmp/xfer` + 删本地 `.xfer`。sha256 双向核对一致（975e7802…）。副作用：5.8MB blob 会留在 GitHub 对象库里（删分支不 gc），下次可考虑直接用源码分支 + 服务器装 Go。
- 服务器拉 `golang:1.27-bookworm` 300 秒没拉完（daemon.json 只配了 `https://docker.1ms.run` 一个镜像加速器），所以「服务器现场构建」这条路当时走不通。
- 新镜像带 attestation manifest，`docker load` 正常处理，无需额外参数。
