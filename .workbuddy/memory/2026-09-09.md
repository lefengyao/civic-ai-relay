## 编辑能力补齐（用户反馈：供应商/模型/模型组无法编辑）

- 根因：① 后端模型组只有 `PUT groups/{id}/models`（整组替换成员），没有改名/启停路由；② 前端只有供应商的 prompt() 改名，模型/组/Key 完全没有编辑入口。
- 后端新增：`PUT groups/{id}`（name/enabled，走 UpdateModelGroup）、`GET groups/{id}/models`、`GET keys/{id}/groups`；store 新增 `GroupModelIDs`/`KeyGroupIDs`。Go struct 无 json tag，路由 payload 用小写 name/enabled、响应是导出名——注意区分。
- 前端统一编辑弹窗（openEdit/checkListHTML/checkedIds），四个实体均可编辑；checkedIds 必须限定 `.check-list input:checked` 否则误抓启停开关；checkListHTML 要同时输出 `checked` 属性（只加样式类会导致保存丢成员）。
- 坑：admin.html 是 go:embed 编译时打包，改前端必须重新 go build 才生效；缓存类字段（TokenLimit 等）后端 nil=不变，无法清空为"不限"。
- 验证方式：playwright-core 端到端浏览器测试（改名→保存→表格刷新断言），脚本 `test-data/ui-edit-shots.js`、`ui-func-test.js` 可复用。
