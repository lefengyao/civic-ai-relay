## 只有跑起来才会发现的问题（都已修）

1. **周期额度静默失效**：`period_limit_start` 是秒级 RFC3339，账目行是 RFC3339Nano，
   SQL 文本比较下 `…48Z > …48.219Z` → 同秒账目被排除。全部窗口边界改 `julianday()`。
2. **播种细节**：未设的列要保 NULL（`COALESCE(col, NULLIF(?,0))`）；金额必须 `ParseFloat × 1e6`，
   `ParseInt` 会把 12.5 截成 12。
3. **`config.Store.Write` 会合并未知键** → 用它删键等于没删；新增 `WriteMapping`（不合并）。
4. **前端把 `TensionPct==0` 当「不限」** → 设完额度的组仍显示不限；改看 Token 三列本身。
5. **自定义周期要同时填天数和至少一项限额才生效**（`periodActive` 既有语义），界面原本没说。
6. 加列后「状态」被挤成两行 → 组名/状态/额度列加 nowrap 与最小宽度。
